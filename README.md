# Daily Assistant
Voice-repeating cartoon character app. APK is built by GitHub Actions on every push to `main`
(see Releases). Edit `www/` to update the app; the installed APK loads content from GitHub Pages.

## Download
Page: https://alamgirabdullahgh.github.io/Daily-Assistant/download.html
Direct APK (always latest): https://github.com/alamgirabdullahgh/Daily-Assistant/releases/latest/download/DailyAssistant.apk
